# tankesmia

Rammeverk for AI-agenter i Individet.

## Formål

Dette repoet er motoren for kunnskapsarbeid i organisasjonen Individet:

- definere prinsipper og metode
- beskrive agent-roller, skills og arbeidsflyt
- produsere grunnlag for analyser, notater og rapporter
- senere: automatisere deler av analyseprosessen

## Foreløpig innhold

- `manifest.md`: grunnleggende prinsipper for Individet
- `skills/`: markdown-baserte skills for AI-agenter
- `docs/`: arbeidsflyt, orkestrering og roadmap

## Arbeidsmåte nå

Arbeidet er for det meste manuelt orkestrert. Skills og dokumentasjon brukes som operativt rammeverk for AI-assistert arbeid.

## Neste steg

1. Definere flere spesifikke skills per temaområde
2. Standardisere mal for analyser som skal publiseres på individet.no
3. Legge til skript for automatisk generering av analyseutkast
